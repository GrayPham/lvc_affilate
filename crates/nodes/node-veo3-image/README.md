# Tạo ảnh Veo3 (Google Labs Flow)

Tạo ảnh bằng Google Labs Flow (Nano Banana). Mỗi dòng prompt thành một ảnh — có thể kèm ảnh tham
chiếu (nối vào cổng tham chiếu, dùng chung cho mọi dòng prompt). Chọn `model`:

- `NARWHAL` — "Banana 2", nhẹ.
- `GEM_PIX_2` — "Banana Pro", mặc định, chất lượng cao nhất.
- `HARBOR_SEAL` — "Lite", nhanh, rẻ nhất.

Ảnh tạo xong ngay (không cần chờ như video). Cần chọn sẵn tài khoản Google (`account`) — chưa hỗ
trợ tự chọn tài khoản.

- Loại: `veo3_image`
- Hợp đồng đầy đủ: `manifest.json`
