# Chụp khung hình

Chụp MỘT khung hình từ video tại một thời điểm -> ảnh PNG bằng ffmpeg.

- Vào: `in` — 1 video (bắt buộc).
- Ra: `out` — 1 ảnh (PNG, kiểu image; nối được vào node Lưu).
- Tham số: `time` (giây, mặc định 0).
- Cần `ffmpeg` trong PATH (hoặc đặt env `LVC_FFMPEG`). Không tải mạng, không tài khoản, không tốn credit.

- Loại: `frame_capture`
- Hợp đồng đầy đủ: `manifest.json`
