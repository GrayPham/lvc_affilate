# Tải video lên

Chọn 1 video từ máy làm nguồn cho các node video (Cắt video, Chụp khung hình, Ghép phân cảnh).

- Vào: (không có)
- Ra: `out` — video (kiểu video, many).
- Tham số: `paths` (danh sách đường dẫn — UI dùng 1 video), `label` (nhãn tuỳ chọn cho chip tham chiếu).
- Thiếu file khi chạy = lỗi nghiêm trọng (dừng cả run). Không tải mạng, không tài khoản.

- Loại: `load_video`
- Hợp đồng đầy đủ: `manifest.json`
