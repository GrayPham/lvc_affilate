# P3c — Tab "Kịch bản" (scripts/scenes) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Người dùng chọn một kịch bản đang có (nhiều cảnh), có các nút **Chạy / Chạy lại / Dừng / Mở thư mục** cho từng cảnh và **Chạy tất cả**, không cần dựng graph tay — parity với bản Python (`scripts_store.py`, `scripts_api.py`).

**Architecture:** Bảng `scripts` + `scenes` (migration 0003, giống Python) trong `lvc-store`; `lvc-engine::scripts` biến các cảnh được chọn thành TXT (`format_txt`) → `Graph` Prompt→Video→Save → `Engine::run_graph` (tái dùng DAG, sự kiện, huỷ) rồi ghi `scenes.task_id` từ `TaskRepo::list_by_run` (khớp `scene_index`); Tauri commands `script_*`; tab React "Kịch bản". Nhập kịch bản cũ từ `tasks.db` Python (read-only) trong `legacy_import`.

**Tech Stack:** như P3. **Spec:** `docs/superpowers/specs/2026-09-16-lvc-seedance-rust-design.md` (§4 graph, §5 engine) + plan P3.

## Global Constraints
Như plan P3 (`docs/superpowers/plans/2026-09-18-p3-tauri-node-graph.md` §Global Constraints): lvc-core thuần; clippy pedantic `-D warnings`; LF; không log prompt/cookie/URL ký; chỉ Tauri commands; không đụng thư mục Python; live tốn credit chỉ khi người dùng bấm Chạy.

## Quyết định (ruling)
- R1 Chạy cảnh = tạo run DAG 1 graph (Prompt(text = `format_txt(cảnh chọn)`) → Video(mặc định từ `AppSettings`, mỗi dòng TXT tự ghi đè bằng hint) → Save(`dir` kịch bản; rỗng → `<output_dir>/<tên kịch bản>`)). `scene_index` trong TaskRow = vị trí dòng trong TXT → map lại `scenes.task_id` bằng thứ tự cảnh đã chọn.
- R2 Cảnh đang `queued/processing` không chạy lại (lỗi `SCENE_RUNNING`); prompt rỗng → `SCENE_EMPTY`. `style` không rỗng và chưa có trong prompt → nối `\nStyle: <style>` (Python `run_scenes`).
- R3 Xoá kịch bản: cảnh đang chạy → `SCENE_RUNNING`; xoá không huỷ task.
- R4 Nhập TXT vào kịch bản: `parse_txt` (lvc-core) → thay toàn bộ cảnh (`replace_scenes`), cảnh đang chạy → từ chối.
- R5 Legacy import: thêm `scripts`/`scenes` từ `tasks.db` Python nếu có bảng; `task_id` cũ giữ nguyên (task đã nhập ở P0) — không mở Chrome.

### Task 1: Rust — store 0003 + `lvc-engine::scripts` + commands `script_*` + legacy import

**Files:** Create `crates/lvc-store/migrations/0003_scripts.sql`, `crates/lvc-store/src/scripts.rs`, `crates/lvc-engine/src/scripts.rs`, `crates/lvc-app/src/commands/scripts.rs`; Modify `crates/lvc-store/src/{lib.rs,legacy.rs}`, `crates/lvc-engine/src/lib.rs`, `crates/lvc-app/src/{lib.rs,commands/mod.rs,commands/fixtures.rs}`, fixtures `app/src/ipc/fixtures/{script_meta,script_doc,script_run_report}.json`.

**Interfaces:**
- Store: `ScriptRepo{create(name, dir) -> ScriptRow, get(id), update(id, name?, dir?), delete(id) -> Vec<task_id>, list_with_counts() -> Vec<ScriptMeta{id,name,dir,created_at,updated_at,total,done,failed,running}>, list_scenes(script_id) -> Vec<SceneRow>, replace_scenes(script_id, Vec<SceneIn>) (id giữ nếu có), set_scene_task(scene_id, task_id), clear_scene_task(scene_id) -> bool}`; `SceneRow{id, script_id, idx, prompt, ratio, duration, model, mode, logo, account, refs: Vec<String>, task_id: Option<String>, updated_at}`; `scripts`/`scenes` schema y hệt Python (cột `refs` JSON).
- Engine: `Engine::run_script(&Arc<Self>, script_id, scene_ids: &[String], style: &str, defaults: &AppSettings) -> Result<ScriptRunReport{run_id: Option<String>, tasks: Vec<(scene_id, task_id)>, errors: Vec<(scene_id, code)>}, EngineError>` (R1/R2); `Engine::import_txt_to_script(script_id, text) -> usize` (R4).
- Commands: `script_list`, `script_create(name, dir)`, `script_update(id, name, dir)`, `script_delete(id)`, `script_get(id) -> ScriptDoc{meta, scenes: Vec<SceneDto{…, taskStatus: Option<String>, failureCode: Option<String>, localPath: Option<String>}>}`, `script_put_scenes(id, scenes: Vec<SceneIn>)`, `script_run(id, sceneIds, style) -> ScriptRunReport`, `script_reset_scenes(id, sceneIds) -> {reset, skipped}`, `script_import_txt(id, text) -> number`. Mã lỗi: `SCRIPT_NOT_FOUND`, `SCENE_RUNNING`, `SCENE_EMPTY`, `SCENE_INVALID` (parse), `TOO_MANY_SCENES` (Limits `batch_max_scenes` nếu có, mặc định 50).
- Legacy: `LegacyImportReport` + `scripts`, `scenes` counts (fixture `import_reports.json` tái sinh).
